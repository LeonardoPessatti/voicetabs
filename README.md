# VoiceTabs

Tabbed text editor where notes are dictated, not typed. Windows 11. Offline. PT-BR + English UI.

See `docs/superpowers/specs/2026-05-20-voicetabs-design.md` for the design.

## Development

```powershell
npm install
npm run tauri dev
```

## Build installer

```powershell
npm run tauri build
```
